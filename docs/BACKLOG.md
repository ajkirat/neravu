# Ideas backlog (not planned, not started)

Reference only. Nothing here is being built until the owner of the project asks for it.
Source: a feature list the owner shared from a ChatGPT conversation about a RentOk-style PG product,
compared with what Neravu already has.

## Gaps against that list
| Area | Not in Neravu yet |
|---|---|
| Dashboard | Profit per property, vacancy loss (rent lost on empty beds), month-on-month trend |
| Properties | Buildings or blocks as a level above rooms |
| Tenants | ID document photo upload, e-signature, police-verification form, check-in checklist |
| Rent | Late fees, pro-rated first and last month, yearly rent increase, advance or multi-month payment |
| Payments | Bank-statement reconciliation, payment proof upload |
| Expenses | Recurring expenses (salaries, rent), budgets per category, staff-submitted expenses for approval |
| Complaints | Tenant-raised tickets, assigning to staff, priority, photos |
| Staff | Granular roles, attendance and salary, task assignment, activity log |
| Tenant app | A no-login tenant portal (dues, receipts, complaints, notices) |
| Notifications | Notice board and broadcast message, SMS, auto-sent receipts |
| Reports | Collection efficiency, dues ageing, per-bed profitability, Excel/PDF export |
| Super admin | Owner accounts, plans, subscription billing, usage (only if sold to other owners) |

## Other ideas
Public page per PG with beds available, photos and an online booking token; food menu and attendance;
visitor log; room inventory.

## Suggested order if the owner asks for more
1. Tenant portal by private link (no login)
2. Late fees, pro-rated rent, recurring expenses
3. Staff roles, attendance, salary, activity log
4. Notice board and broadcast message
5. ID document upload (needs file storage)
6. Super admin and subscriptions

Decisions the owner has already made: owner-only product for now (no tenant app, no super admin).
